# La Tavola Seaview Digital Platform

## Project Overview
This project is a high-conversion, narrative-driven digital experience for La Tavola Seaview, a premium Mediterranean restaurant.

## Architecture & Design
The architecture abandons traditional "hero -> menu -> gallery" landing page templates in favor of a continuous, emotionally immersive scrolling narrative.

### Core Narrative Flow:
1. **Arrival**: Cinematic introduction establishing the "Seaview" identity.
2. **Atmosphere**: Highlights the ambient and emotional aspects of the dining experience using scroll-triggered animations.
3. **Culinary Journey**: A psychological pricing-optimized, structured browsing experience for the menu with distinct visual hierarchy.
4. **Social Proof**: Trust reinforcement integrated naturally into the narrative.
5. **Booking Experience**: A frictionless, high-urgency reservation flow designed to maximize direct conversions and reduce WhatsApp reliance.

### Tech Stack
- React 18 + Vite
- TypeScript
- Tailwind CSS (Custom Design System with Deep Sea Navy, Pearl White, Sunset Gold)
- Framer Motion (for scroll behavior and micro-interactions)
